## Overview

A machine learning pipeline for the **Pump It Up** classification task: predicting the operational status of water pumps in Tanzania from tabular metadata. It covers data preprocessing, feature engineering and model evaluation.

## Model comparison

A comparative experiment with five classification algorithms:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- XGBoost

Their performance is evaluated and compared with appropriate metrics to find the most effective model for the task.
